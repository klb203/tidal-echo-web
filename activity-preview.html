自由活动 · 预览

activity-pack.css / .js 的独立试衣间。 正式页面里它挂在左侧菜单上。思路来自 death34018-hue/AionsHome 的「娱乐室」—— MCP 服务接入 + AI 自主探索 + 行动日志 + 经历总结归档。

主题

它做什么

  • 设时间：活动时段（可跨零点）、两次之间至少隔多久、每天最多几次。 到点了它会自己出门逛一趟。
  • 接服务：填远程 MCP 地址，点「测连通 / 发现工具」会把那个服务的工具拉回来， 之后它就能调。
  • 带回记忆：逛完由模型收尾写一段总结，经宿主的 /app/memory/save 写进记忆库 —— 分区可选 （事件 / 参考资料 / 工作记忆 / 摘要 / 故事 / 我的房间 / 留给西西的话）。
  • 行动日志：它调了哪个工具、参数是什么、拿回什么，一步一步都看得见。

⚠️ 只有页面开着它才会跑。这是个静态 PWA，浏览器里没有常驻进程 —— 关掉页面就是关掉。所以调度是「开着时每分钟查一次 + 回到前台立刻补检」， 错过的时段会在下次打开时补跑一次。真要 7×24 得把这份配置搬到后端当定时任务， 这份配置就是它的草稿。

预览页里没有宿主的记忆接口，所以「写进记忆」会明确告诉你写不了 —— 这是有意的：宁可说写不了，也不假装写了。在正式前端里打开就正常。

接入正式页面要动的地方

  • index.html 的 <head> 里 link 本包 css。
  • #menuPanel 的 <nav class="menu-list"> 里加一个 data-menu="activity" 的菜单项。
  • 菜单点击处理里加一条分支 → closeMenu(); openActivity();
  • </body> 之前加 <script defer src="activity-pack.js"></script>。
  • sw.js 的 CACHE 版本号 +1，并把两个包文件加进 PRECACHE。

面板 DOM 由包自己注入，不需要在 index.html 里手写标记。
