群聊 · 预览

这是 group-chat-pack.css / .js 的独立试衣间 —— 正式页面里它挂在左侧菜单的「群聊」上。这里可以直接开、可以直接用，配色与正式页面完全一致。

主题

在这个预览里怎么试

  • 点「打开群聊」→ 在输入框里写一件事，回车发出去。
  • 打一个 @ 会弹出成员列表；也可以直接点上面那排成员小胶囊来 @ 人。
  • 看它自己往下跑：主助手派活 → 执行者回报 → 主助手收尾， 最后冒出一张红卡等你拍板。这就是「三层协作」的完整一圈。
  • 切到「进度」页看任务看板五区；点右上角 ⋯ 看角色配置与群规。

预览里没有后端地址，所以三个成员都解析不出可用连接 —— 群聊会自动切到演示模式：流程、任务账本、待确认卡片都是真的， 只有文案是预置的，而且每条都会带「演示」角标。 在正式页面里配好「设置 → 云端后端」之后，它会真的分别去调 DeepSeek（主助手）、Kimi（执行者）、 智谱 GLM（互审者）。

接入正式页面要动的地方

  • index.html 的 <head> 里 link 本包的 css。
  • #menuPanel 的 <nav class="menu-list"> 里加一个 data-menu="groupchat" 的菜单项。
  • 菜单点击处理里加一条分支 → closeMenu(); openGroupChat();
  • </body> 之前加一行 <script defer src="group-chat-pack.js"></script>。
  • sw.js 的 CACHE 版本号要 +1，否则装了主屏的手机会继续用旧壳。

面板 DOM 由包自己注入，所以不需要在 index.html 里手写那一大坨标记。
