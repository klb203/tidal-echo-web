万花筒 · 预览

这是 rp-channel-pack.css / .js 的独立试衣间 —— 正式页面里它挂在左侧菜单上。机制参照 kaleidoscope-rp（摇老虎机开世界 / 旁白与 NPC 召唤制 / 红线分层）。

主题

在这个预览里怎么试

  • 点「打开万花筒」→ 先摇第一排、第二排，再点生成世界卡。 预览里没配后端，会退化成本地拼装——把摇到的词原样拼成世界卡，不编内容。
  • 点用这张开演 → 进扮演界面。说话需要模型；没配的话会给你一条明确的错误提示，而不是假装演。
  • 右上角 ⋯ 进配置：人设 / 尺度 / 红线 / 三个模型位全是空位，由你填。
  • 配置里还能开成人模式（解锁第三排 状态 / 场所 / 要求）和私密打码（内容默认模糊，点气泡才显形）。
  • 词池也能改：配置页底部「改词池」，每行一条、整类可清空。
  • 底部还有一个切换：老虎机 ⇄ 大富翁。切过去是另一套界面。

大富翁是接 MCP 的（参考 RennAkira/spicy-monopoly）：本包当 MCP 客户端， 直接调它那 6 个工具（monopoly_help / new_game / roll / game_action / game_info / game_admin）， 不自己写玩法、也不自己编骰子和金币。棋盘是原样贴出来的（上游明确要求别重画）。 掷骰 / 查状态 / 跳过这几个按钮是不经过模型的直连兜底 —— 万一模型不支持工具调用， 光靠它们也能把一局玩完。



大富翁有三层，每层都是独立一整页：①「连接」取荷官规则 → ②「开局」是把参数在对话里问清楚（不是丢一张表给你填），聊完它自己开局 → ③「牌桌」是对局本身：棋盘钉在顶上（点「棋盘」可收起），下面就是聊天， 掷骰 / 查状态 / 404 停下都在手边。开局完会直接落到牌桌上。

AI 能自己玩。牌桌右上 ⚙ 里可以逐席设「你来玩 / AI 来玩」（默认 TA 是 AI）， 再写一句它的玩法风格。设成 AI 的那一席，轮到他时模型自己拍板 —— 该掷骰就掷、 该选结算参数就自己选，不会停下来问你；你还能让它「自动跑 N 轮」连续走。 它只在三种情况下才停下等你：你主动说话、牵涉安全词、或信息不足（这时它会标【等你】）。 两边都设「你来玩」也能正常打，只是没有代打。

端点默认指向上游公开实例，想放自己云服务器就改那一栏。三个前提缺一不可： 端点必须是 HTTPS（Pages 是 HTTPS，HTTP 会被按混合内容拦掉）、 必须回 CORS 头、云服务器的安全组和 ufw 都要放行该端口。

这个包不含任何内容。人设、尺度、口味红线全部是空着的输入框 —— 这是照抄参考项目最值得学的一点： 内容住在配置里，改玩法不动代码、不用重发版本。 结构红线（不许替你说话 / 旁白不写心理 / 打「停」出戏 / 主角可以沉默）是写死的四条， 剩下的口味红线你自己删改。

三个机制

  • 老虎机：不让人对着空白框写设定。摇词 → 世界卡。第三排必是三个槽（状态 / 场所 / 要求）， 只给一个词生成器没操作空间，产出会高度雷同。
  • 旁白召唤制：旁白不是每轮自动出场（那会让环境描写淹没对话）， 由主角在正文里埋 [cue:…] 点名叫出来。
  • NPC 按需登场：[npc:名字:指示]。关键是由主角判断该谁说话， 而且给它「你可以一个字都不写」的权限 —— 不给这个权限，模型每轮都会硬接，在不该开口的时候开口。

接入正式页面要动的地方

  • index.html 的 <head> 里 link 本包的 css。
  • #menuPanel 的 <nav class="menu-list"> 里加一个 data-menu="rp" 的菜单项。
  • 菜单点击处理里加一条分支 → closeMenu(); openRp();
  • </body> 之前加一行 <script defer src="rp-channel-pack.js"></script>。
  • sw.js 的 CACHE 版本号 +1，并把两个包文件加进 PRECACHE。

面板 DOM 由包自己注入，不需要在 index.html 里手写那一大坨标记。
